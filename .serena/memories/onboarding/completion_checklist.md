# Task Completion Checklist

1. **Verify Logic**: Ensure the feature or fix works as intended.
2. **Add Tests**: Update or add tests in the `tests/` directory.
3. **Format Code**: Run `deno fmt`.
4. **Lint Code**: Run `deno lint`.
5. **Run Tests**: Run `deno test --allow-read --allow-write` and ensure all pass.
6. **Check CI Compatibility**: Ensure Deno version 2.7.6 is used and JSR imports are correct.
