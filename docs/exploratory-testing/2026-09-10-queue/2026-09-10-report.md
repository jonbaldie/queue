## Confirmed findings

### #96 — Missing `WWW-Authenticate` on 401

Three fresh real servers returned `401 Unauthorized` with no
`WWW-Authenticate` header for an unauthenticated protected request. The
service was configured with a non-empty Bearer token, and the endpoint was
correctly protected. The missing challenge violates the HTTP 401 response
contract and prevents challenge-driven clients from discovering the Bearer
scheme. See [the replay](./auth-challenge-replay.txt) and [issue #96](https://github.com/jonbaldie/queue/issues/96).

### #95 — Unicode queue-name limit uses UTF-16 units

The documented `maxLength: 128` queue-name limit accepts 128 BMP characters but
rejects 128 emoji code points because JavaScript `String.length` counts each
emoji as two UTF-16 units. The 64/65 emoji boundary and the 128 BMP control
were reproduced on three fresh servers. See [the replay](./unicode-queue-name-replay.txt) and [issue #95](https://github.com/jonbaldie/queue/issues/95).
